re.lib – Konstrukteur-Bibliothek (Android-APK + Windows-App)
==========================================================

EINMALIG EINRICHTEN
1. Auf github.com ein neues Repository "re-lib" anlegen (öffentlich, wie re-kalk).
2. Den kompletten Inhalt dieses Ordners hochladen (auch den Ordner .github!),
   z. B. mit GitHub Desktop oder "Add file > Upload files".
3. Im Repository: Settings > Pages > "Build and deployment" > Source: "GitHub Actions" wählen.
4. Reiter "Actions" > "re.lib bauen" > "Run workflow" (dauert ca. 5 Min.).

ANDROID
5. Releases (rechts auf der Repo-Seite) > neueste Version > reLib.apk herunterladen,
   antippen, "Aus dieser Quelle installieren" erlauben. Das ist nur beim ersten Mal nötig.

WINDOWS
6. In Edge öffnen: https://<dein-github-name>.github.io/re-lib/
   Menü "..." > Apps > "Diese Website als App installieren".
   re.lib erscheint dann im Startmenü / in der Taskleiste und läuft auch offline.

UPDATES
- Neue Version: geänderte Dateien ins Repository hochladen. GitHub baut automatisch
  eine neue Version (Versionsnummer = Laufnummer).
- In der App erscheint beim Start "Update verfügbar" bzw. über den Knopf "⟳ Updates"
  oben rechts. "Jetzt aktualisieren" antippen – fertig, keine Neuinstallation nötig.

PDF-EXPORT (Bereich "Berechnungen")
- Unten in jeder Berechnung: Projekt, Position und Bearbeiter eintragen > "Als PDF speichern / drucken".
- Windows: Das PDF öffnet sich im PDF-Viewer von Edge > Drucken oder Speichern.
- Android: Das Teilen-Menü öffnet sich > z. B. "Drucken", "In OneDrive speichern" oder per Mail senden.
- WICHTIG (einmalig): Der PDF-Export braucht zwei neue Android-Bausteine (Dateien + Teilen).
  Diese kommen nicht über das In-App-Update, darum nach diesem Update die neue reLib.apk
  EINMAL aus den Releases installieren (über die alte drüber, Daten bleiben erhalten).
  Danach laufen alle weiteren Updates wieder über den Update-Knopf.
